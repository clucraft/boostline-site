Setting up the BMW DME data

Without this data, a car only shows the standard OBD-II channels. Import it once to get boost target, wastegate, rail pressure, lambda target, per-cylinder timing and knock, VANOS and hundreds more.

The measurements come from BMW's diagnostic files, decoded by the open-source bmw-unified-db project. The data is BMW-copyrighted, so Boostline downloads it to your device instead of shipping it. You need an internet connection for the download; the car doesn't need to be connected.

On an iPhone or iPad, do this at home on a WiFi network with internet, before you go to the car. The adapter's WiFi network has no internet.

1. Open Settings › BMW DME data

Open Settings. The BMW DME data card is right below Connection.

2. Tap Download & import

Boostline then:

  1. Downloads the latest release of bmw-unified-db from GitHub (about 130 MB).
  2. Checks it against the release's SHA-256 checksum.
  3. Unpacks it and keeps only the engine computer (DME) tables, about 3 MB.
  4. Deletes the temporary files.

Progress appears next to the buttons: Downloading…, Verifying checksum…, Unpacking…, Extracting DME tables…. On a normal connection it takes about a minute.

3. Check the result

When the import finishes, the card shows Imported data with the source version, the date, and how many engine computers and measurements were imported. Show list shows what's covered:

  • DME data: the name of BMW's data file for that engine computer.
  • Engines / Chassis: where that file is used.
  • Channels: how many measurements it provides.
  • Auto: yes means Boostline recognizes it by itself when you connect; manual means you choose it yourself (step 4).

4. Leave DME selection on Auto, unless your car needs a manual choice

With Auto (recommended), Boostline asks the engine computer to identify itself when you connect and picks the matching data. Choose an entry in the DME selection list yourself when:

  • Your car has a 2016–2019 F-series B58 (first generation: 340i, 440i, M240i, M140i, 540i). BMW's files for that engine computer (dme_bx80, dme_bx81, dme_bx82) carry no ID to match. Pick the one for your car's integration level (I-level), which E-Sys, ISTA or BimmerCode can show you: dme_bx80 is I-410, dme_bx81 is I-411, dme_bx82 is I-420. If you don't know your I-level, start with dme_bx82; if many channels show “—”, try the others.
  • The card says “(no match)” after you connect. Choose the entry for your engine, and please report the ID it showed so that Auto can learn it.

Changes take effect the next time you connect.

5. Connect and check

Connect as usual. When the data is in use:

  • Top bar: tap the car (VIN) next to the connection status. The menu shows DME data, for example dme8ff_r.
  • Settings: the BMW DME data card shows the ID your engine computer reported and which data it matched.
  • Channels: BMW channels appear with English names, such as Boost target, Wastegate position, Rail pressure target and Ignition timing cyl 1–6. A DME group holds every other measurement under BMW's original (German) names; search to find them.

If the car refuses a BMW measurement that also exists in OBD-II (such as engine speed), Boostline goes back to the OBD-II reading for that channel by itself.

Updating, importing a file, removing

  • Update from GitHub imports the newest bmw-unified-db release. Do this now and then; the project keeps improving.
  • Import file… works without internet on the device: download bmw.sqlite.gz from the bmw-unified-db releases elsewhere, copy it over (on an iPhone or iPad, into the Files app), and choose it here. Both .sqlite and .sqlite.gz work.
  • Remove deletes the imported data. Boostline goes back to the standard OBD-II channels.

Troubleshooting

Problem What to do
The download fails Check that the device has internet (not the adapter's WiFi). A firewall or proxy may also block GitHub; use Import file… with a downloaded bmw.sqlite.gz.
“(no match)” after connecting Choose the DME data yourself (step 4) and report the ID.
Some channels show “—” The engine computer didn't answer for that measurement. Run Settings › Connection › Run diagnostics and send the report and a log (see Support).
