Support

Answers to common questions, and how to get in touch.

Contact

Report a problem or ask a question by opening an issue on GitHub: github.com/clucraft/boostline-site/issues (you need a free GitHub account). Please include:

  • Your device and iOS version, and the Boostline version (Settings › About).
  • Your car (model, year, engine) and which adapter you use.
  • For connection problems, the report from Settings › Connection › Run diagnostics. It is saved in the Files app under Boostline › Diagnostics. It may contain your car's VIN; remove it if you prefer.

Getting connected

How do I connect to my car?
  1. Plug the MHD or bootmod3 WiFi adapter into the car's OBD port and switch the ignition on.
  2. In the iPhone's WiFi settings, join the adapter's network: MHD ENET for the MHD adapter (not MHD ECA), or BM3-NET… for the bootmod3 adapter.
  3. Open Boostline, choose the adapter in Settings › Connection, and tap Connect in the top bar.
  4. The first time, iOS asks to let Boostline find devices on your local network. Tap Allow.
Boostline can't find my adapter
  • Check that the phone is on the adapter's WiFi network and that the ignition is on.
  • Check that local network access is allowed: iOS Settings › Privacy & Security › Local Network › Boostline.
  • Enter the adapter's IP address in Settings › Connection › Gateway IP. iOS doesn't let apps search the network the way a computer can, so Boostline tries the most likely addresses first.
  • If the adapter's own app (MHD, bootmod3) is connected to the car, close it and try again.
  • Still stuck? Run diagnostics and send the report (see Contact).
Can I use an ENET cable?

It should work with an Ethernet adapter for the iPhone or iPad (USB-C to Ethernet), but it hasn't been tested yet. Please report how it goes.

Channels and data

I only see a few channels

Without the BMW DME data, a car only reports the standard OBD-II channels. Import the data once, at home on a WiFi network with internet: BMW data guide. The adapter's WiFi has no internet, so do it before you go to the car.

Some channels show “—”

The engine computer didn't answer for that measurement. Some cars don't have every measurement. If a channel that also exists in OBD-II (such as engine speed) is refused, Boostline switches to the OBD-II reading by itself. For other channels, run diagnostics and send the report with a log.

Where are my logs?

In the Files app: On My iPhone (or On My iPad) › Boostline, in the folders Logs, Dyno, Drag and Exports. Logs are CSV files you can open in a spreadsheet or send to your tuner.

Logging stopped when I switched apps

iOS pauses apps in the background, so keep Boostline on screen while logging. It keeps the screen awake while it is connected.

Safety

Can Boostline harm my car?

Boostline only reads data, using read-only diagnostic requests. It doesn't flash, code, clear fault codes or change anything in the car.

Where can I do dyno and drag runs?

Only where full-throttle acceleration is legal and safe: on a closed course, a drag strip or a dyno, never on public roads. Set the run up before you drive and keep your eyes on the road; Boostline records the run on its own. Road-dyno figures are estimates from acceleration, not measurements on a calibrated dynamometer.
